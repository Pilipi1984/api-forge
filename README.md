# ApiForge

![.NET Tests](https://github.com/Pilipi1984/api-forge/actions/workflows/dotnet-test.yml/badge.svg?branch=master)

Repositorio de ejemplo que genera soluciones .NET a partir de una especificación OpenAPI.

El workflow CI ejecuta build + tests y publica los resultados (incluida la cobertura) como artefactos en GitHub Actions.
